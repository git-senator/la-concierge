# Latin America — Private Concierge

Одностраничный сайт частного консьерж-сервиса по Бразилии и Латинской Америке.

- Пять языков: русский (основа), английский, португальский, испанский, итальянский.
- Двадцать три услуги, пять направлений, форма заявки.
- Без фреймворков и сборки: HTML, CSS и обычный JavaScript.

Исходники варианта живут в `v2/` основного проекта, здесь — собранная версия для показа.
